# 想法到项目流程

## 目的

让适合执行的想法从原始捕获逐步变成可执行项目，同时避免每个冲动想法都变成项目负担。

注意：不是所有想法都要进入本流程。音乐创作、内容创作、学习研究、职业资产、生活系统等想法先走 [[Classify New Idea|新想法分类流程]]。

## 流程

```text
收集箱 -> 想法简报 -> 孵化 -> 项目启动说明 -> 项目卡片 -> 项目 repo 知识库
```

进入本流程前，先确认这个想法确实适合变成项目。

如果想法还没有形成文档，或尚未盘点现有能力与所需工具，先走 [[Idea Documentation and Capability Discovery|想法文档化与能力检索]]。

## 阶段规则

### 1. 收集箱

用于原始想法，不需要模板。

### 2. 想法简报

当一个想法反复出现，或看起来可以行动时，创建想法简报。

进入孵化前需要明确：

- 问题是什么
- 为什么重要
- 当前想法形态
- 最小验证动作

### 3. 孵化

用于研究、验证、收集案例和梳理约束。

### 4. 项目启动说明

开始执行前，先写项目启动说明。

变成活跃项目之前需要明确：

- 为什么做
- 目标结果
- 范围
- 第一个里程碑
- 风险

### 5. 创建项目

创建：

- Jarvis 项目卡片
- `~/Workspace` 下的项目 repo，或连接已有 repo
- 项目内知识库
