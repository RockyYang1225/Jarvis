# Email Templates

Use these as structure, not fixed wording.

## Follow-Up

```text
Subject: Follow-up on <topic>

Hi <name>,

I wanted to follow up on <context>.

<Main point or question>

Next step:
- <clear ask>

Best,
<sender>
```

## Project / Version Acceptance

```text
Subject: <project> version acceptance review: <version or milestone>

Hi <name>,

The latest <project> update is ready for review.

Summary:
- Goal:
- Key changes:
- Validation:
- Known risks:

Review request:
- <what the recipient should check>

Links:
- <version doc>
- <demo / repo / deployment>

Best,
<sender>
```

## Intro / Outreach

```text
Subject: <short reason for reaching out>

Hi <name>,

I'm <sender/context>. I'm reaching out because <reason>.

<Specific value, question, or proposal>

Would you be open to <next step>?

Best,
<sender>
```

## Short Notification

```text
Subject: <topic>

Hi <name>,

<One-sentence update.>

Details:
- ...

Next step:
- ...

Best,
<sender>
```
