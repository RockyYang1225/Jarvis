# Create Project From Idea Prompt

Use this prompt when turning an Idea Brief into a project.

```text
Turn this Idea Brief into a project proposal.

Inputs:
- Idea Brief
- related notes
- current active projects

Produce:
1. Project Charter draft
2. suggested project name
3. suggested repo path under `~/Workspace`
4. first milestone
5. initial project-home.md draft
6. risks and unknowns
7. recommendation: start, incubate, or park

Do not create files until I confirm.
```
