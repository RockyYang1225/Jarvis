# AI Weekly Review Prompt

Use this prompt when asking an AI assistant to help review Jarvis.

```text
Review my Jarvis knowledge system for this week.

Inputs to inspect:
- 00_Home/Current Focus.md
- 10_Workspace/Projects.md
- 10_Workspace/Active Projects/
- 30_Ideas/Inbox/
- 30_Ideas/Idea Briefs/
- 50_Reviews/Weekly/

Produce:
1. What changed this week
2. Active projects that need attention
3. Ideas that should be promoted, parked, or clarified
4. Knowledge that should be extracted
5. System rules or templates that should be updated
6. A draft Weekly Review note

Do not move, delete, archive, or rewrite files without explicit confirmation.
```
